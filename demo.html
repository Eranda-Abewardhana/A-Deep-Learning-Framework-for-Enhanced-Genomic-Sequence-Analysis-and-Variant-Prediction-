Real-World Analogy
ClinVar is a global library of solved cases where clinical labs upload medical evidence on whether specific mutations caused disease in patients.

📚 Complete Thesis Biological Glossary Reference
GRCh38 Reference Genome

Standardized human reference genome assembly used for coordinate alignment and sequence extraction.

BRCA1 / BRCA2

Key tumor suppressor genes. Pathogenic variants impair DNA repair, increasing hereditary cancer risk.

Anchor Crop / Pad (1024 bp)

Centers the variant site at position 512 inside a 1,024 base pair context window.

SNV (Single Nucleotide Variant)

Single base substitution (e.g. G → A). Most common small-scale genetic variation.

Indel / Insertion / Deletion

Small-scale alterations involving addition or removal of base pairs.

Pathogenic vs. Benign

Pathogenic variants cause disease; Benign variants are harmless natural variations.

VUS (Uncertain Significance)

Variants with ambiguous or conflicting clinical evidence requiring AI computational prioritization.

Explainable AI (XAI / Attribution)

Methods (Integrated Gradients, Guided AbsoluteGrad, ISM) attributing pathogenicity back to nucleotide positions.

Model Overview — MutationAwareBRCAClassifierV2

A dual-branch architecture that processes reference and alternate allele sequences independently through multi-kernel CNNs and a shared Transformer encoder, then computes an explicit element-wise difference (Δ-representation) to capture mutation-specific signal before gated attention pooling and classification.

DNA (REF + ALT) → One-Hot (5ch) → Multi-Kernel CNN → 1×1 Proj → Pos Enc → Transformer ×2 → Δ = REF−ALT → Gated Pool → MLP → P(path)
🧬

Dual-Branch Input

Reference and alternate allele sequences are one-hot encoded with a 5th mutation-marker channel, then processed by separate multi-kernel CNNs (kernel sizes 3, 7, 15) to capture motifs at multiple resolutions.

🔄

Shared Transformer

After projection to 128-d, both branches pass through a shared 2-layer Transformer encoder (4 heads, FFN=256) with sinusoidal positional encoding to capture long-range dependencies.

∆

Δ-Learning Module

Element-wise difference between contextualized REF and ALT representations isolates the mutation-specific signal. Ablation shows this is the single most important component (ROC AUC drops from 0.836 to 0.551 without it).

🎯

Gated Attention Pooling

Separate learned attention gates for REF, ALT, and Δ streams weight each position's contribution before concatenation into a 384-d vector for the classification MLP (256→64→1).

🔍

Attribution via |Grad×Input|

Per-position importance scores are computed by backpropagating through the full model and taking the absolute value of gradient×input, summed over the 4 base channels. The heatmap concentrates near the mutation site.

📊

Training & Evaluation

Trained on ClinVar BRCA1/BRCA2 variants with cross-validation. Evaluated prospectively on NCBI variants (943 samples). Full model: ROC AUC 0.836, AUPRC 0.578, MCC 0.413.

Ablation Study — Component Contribution to ROC AUC

Each bar shows the ROC AUC when the named component is removed. The full proposed framework achieves 0.836; every component removal degrades performance.

Key Findings

Δ-Learning is Critical

Without the delta module, AUC drops to 0.551 — near random. The model cannot distinguish pathogenic from benign variants without explicitly comparing REF and ALT representations.

Transformer Adds Context

Removing the Transformer drops AUC to 0.677. Long-range sequence context is important but less critical than the Δ-learning mechanism.

Multi-Kernel CNN > Single-Scale

Multi-kernel CNN contributes meaningfully (AUC 0.794 without it), confirming that multi-resolution motif detection helps feature extraction.

Dual Input > Single Sequence

A single-sequence baseline achieves only 0.619, proving that separately encoding REF and ALT is superior to concatenation.
