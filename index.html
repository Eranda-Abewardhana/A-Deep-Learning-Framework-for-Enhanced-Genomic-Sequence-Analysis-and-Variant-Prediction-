Model Overview — MutationAwareBRCAClassifierV2

A dual-branch architecture that processes reference and alternate allele sequences independently through multi-kernel CNNs and a shared Transformer encoder, then computes an explicit element-wise difference (Δ-representation) to capture mutation-specific signal before gated attention pooling and classification.

DNA (REF + ALT) → One-Hot (5ch) → Multi-Kernel CNN → 1×1 Proj → Pos Enc → Transformer ×2 → Δ = REF−ALT → Gated Pool → MLP → P(path)
🧬

Dual-Branch Input

Reference and alternate allele sequences are one-hot encoded with a 5th mutation-marker channel, then processed by separate multi-kernel CNNs (kernel sizes 3, 7, 15) to capture motifs at multiple resolutions.

🔄

Shared Transformer

After projection to 128-d, both branches pass through a shared 2-layer Transformer encoder (4 heads, FFN=256) with sinusoidal positional encoding to capture long-range dependencies.

∆

Δ-Learning Module

Element-wise difference between contextualized REF and ALT representations isolates the mutation-specific signal. Ablation shows this is the single most important component (ROC AUC drops from 0.836 to 0.551 without it).

🎯

Gated Attention Pooling

Separate learned attention gates for REF, ALT, and Δ streams weight each position's contribution before concatenation into a 384-d vector for the classification MLP (256→64→1).

🔍

Attribution via |Grad×Input|

Per-position importance scores are computed by backpropagating through the full model and taking the absolute value of gradient×input, summed over the 4 base channels. The heatmap concentrates near the mutation site.

📊

# 5. Sequence Utility Functions
# ============================================================
BASES    = ["A", "C", "G", "T", "N"]
BASE2IDX = {b: i for i, b in enumerate(BASES)}

def clean_seq(seq: str) -> str:
    """Map non-ACGT characters to N."""
    return "".join(ch if ch in "ACGT" else "N" for ch in str(seq).upper())

def clean_seq_loose(seq: str) -> str:
    """
    Preserve ACGTN; map only truly unknown IUPAC codes to N.
    Used for mismatch checking so ambiguous genome bases don't cause
    false mismatches.
    """
    return "".join(ch if ch in "ACGTN" else "N" for ch in str(seq).upper())

def one_hot_encode(seq: str) -> np.ndarray:
    """One-hot encode a nucleotide sequence → float32 array [L, 5]."""
    seq     = clean_seq(seq)
    indices = np.frombuffer(seq.encode(), dtype=np.uint8)
    arr     = np.zeros((len(seq), 5), dtype=np.float32)
    lookup  = {ord("A"): 0, ord("C"): 1, ord("G"): 2, ord("T"): 3}
    for byte, col in lookup.items():
        arr[indices == byte, col] = 1.0
    arr[~arr.any(axis=1), 4] = 1.0   # N fallback
    return arr

def decode_onehot(x: np.ndarray) -> str:
    """Reverse one-hot [L,5] → nucleotide string."""
    return "".join(BASES[i] for i in x.argmax(axis=-1))

def anchor_crop_or_pad(seq: str, target_len: int, anchor: int,
                        pad_char: str = "N") -> str:
    """
    Crop/pad sequence so `anchor` position stays centred in the window.
    Fixes the large-insertion problem: mutation site is always at
    position target_len//2 regardless of indel size.
    """
    seq  = clean_seq(seq)
    half = target_len // 2
    left = anchor - half
    right = left + target_len
    if left < 0:
        seq   = pad_char * (-left) + seq
        left, right = 0, target_len
    chunk = seq[left:right]
    if len(chunk) < target_len:
        chunk += pad_char * (target_len - len(chunk))
    return chunk

def get_chr_name(chrom: str) -> str:
    chrom = str(chrom)
    return chrom if chrom.startswith("chr") else f"chr{chrom}"

def build_ref_alt_window(chrom, pos_1based, ref_allele, alt_allele,
                          genome, window_size=1024):
    """
    Build paired REF/ALT windows centred on the variant site.
    Handles SNPs, insertions, deletions, and indels correctly.
    """
    chrom          = get_chr_name(chrom)
    ref_allele_raw = str(ref_allele).upper()
    alt_allele_raw = str(alt_allele).upper()
    ref_allele     = clean_seq(ref_allele_raw)
    alt_allele     = clean_seq(alt_allele_raw)

    v_start0 = int(pos_1based) - 1
    v_end0   = v_start0 + len(ref_allele)

    fetch_extra = max(len(alt_allele), len(ref_allele), window_size // 2) + window_size // 2
    left_start0 = max(0, v_start0 - fetch_extra)
    right_end0  = v_end0 + fetch_extra

    ref_full        = str(genome[chrom][left_start0:right_end0])
    local_var_start = v_start0 - left_start0
    local_var_end   = local_var_start + len(ref_allele)

    # IUPAC-tolerant mismatch check
    observed = clean_seq_loose(ref_full[local_var_start:local_var_end])
    expected = clean_seq_loose(ref_allele_raw)
    if len(observed) != len(expected):
        return None, None, None
    for ob, ex in zip(observed, expected):
        if ob != ex and ob != "N" and ex != "N":
            return None, None, None

    ref_full = clean_seq(ref_full)
    alt_full = ref_full[:local_var_start] + alt_allele + ref_full[local_var_end:]

    ref_seq = anchor_crop_or_pad(ref_full, window_size, anchor=local_var_start)
    alt_seq = anchor_crop_or_pad(alt_full, window_size, anchor=local_var_start)

    var_start_in_window = window_size // 2
    return ref_seq, alt_seq, var_start_in_window

class PositionalEncoding(nn.Module):
    def __init__(self, d_model: int, max_len: int = 4096):
        super().__init__()
        pe  = torch.zeros(max_len, d_model)
        pos = torch.arange(0, max_len, dtype=torch.float32).unsqueeze(1)
        div = torch.exp(torch.arange(0, d_model, 2).float() *
                        (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(pos * div)
        pe[:, 1::2] = torch.cos(pos * div)
        self.register_buffer("pe", pe.unsqueeze(0))

    def forward(self, x):
        return x + self.pe[:, :x.size(1), :]


class MultiKernelCNN(nn.Module):
    """Parallel Conv1D branches with kernels k∈{3,7,15} for multi-scale
    local feature extraction."""
    def __init__(self, in_ch=5, branch_ch=32, kernels=(3, 7, 15)):
        super().__init__()
        self.branches = nn.ModuleList([
            nn.Sequential(
                nn.Conv1d(in_ch, branch_ch, kernel_size=k, padding=k // 2),
                nn.BatchNorm1d(branch_ch),
                nn.GELU(),
            )
            for k in kernels
        ])
        self.out_ch = branch_ch * len(kernels)

    def forward(self, x):
        return torch.cat([b(x) for b in self.branches], dim=1)


class MutationAwarePooling(nn.Module):
    """Learned attention gates boosted by |Δ| magnitude so that positions
    with large REF-vs-ALT differences receive higher weight.
    use_delta=False gives plain attention (for the Δ-ablation baseline)."""
    def __init__(self, d_model: int, use_delta: bool = True):
        super().__init__()
        self.use_delta  = use_delta
        self.ref_gate   = nn.Linear(d_model, 1)
        self.alt_gate   = nn.Linear(d_model, 1)
        self.delta_gate = nn.Linear(d_model, 1) if use_delta else None

    def forward(self, ref_h, alt_h, delta_h=None):
        use_d      = self.use_delta and delta_h is not None
        delta_mag  = delta_h.abs().mean(dim=-1) if use_d else 0.0
        ref_attn   = torch.softmax(self.ref_gate(ref_h).squeeze(-1) + delta_mag, dim=-1)
        alt_attn   = torch.softmax(self.alt_gate(alt_h).squeeze(-1) + delta_mag, dim=-1)
        ref_g      = (ref_h * ref_attn.unsqueeze(-1)).sum(1)
        alt_g      = (alt_h * alt_attn.unsqueeze(-1)).sum(1)
        if use_d:
            delta_attn = torch.softmax(self.delta_gate(delta_h).squeeze(-1) + delta_mag, dim=-1)
            delta_g    = (delta_h * delta_attn.unsqueeze(-1)).sum(1)
        else:
            delta_attn, delta_g = None, None
        return ref_g, alt_g, delta_g, ref_attn, alt_attn, delta_attn


class MutationAwareBRCAClassifierV2(nn.Module):
    """Dual-branch mutation-aware classifier.

    tie_branches=True (default) makes REF and ALT share ONE encoder — a
    Siamese/twin network. This is what makes Δ-learning meaningful:

        delta_h = f(alt) - f(ref)

    With a shared f, identical sequences give delta_h == 0 EXACTLY, so the
    Δ channel carries only the variation. With independent per-branch
    weights (tie_branches=False) delta_h = f_alt(x) - f_ref(x) != 0 even for
    identical inputs, and the Δ channel is dominated by the arbitrary
    asymmetry between the two branches rather than by the mutation.

    The ablation switches (use_cnn / use_transformer / use_delta /
    single_seq) build the baseline architectures for the ablation study.
    """
    def __init__(self, in_ch=5, cnn_branch_ch=32, kernels=(3, 7, 15),
                 transformer_dim=128, nhead=4, num_layers=2,
                 ff_dim=256, dropout=0.1, tie_branches=True,
                 use_cnn=True, use_transformer=True, use_delta=True,
                 single_seq=False):
        super().__init__()
        self.tie_branches    = tie_branches
        self.use_cnn         = use_cnn
        self.use_transformer = use_transformer
        self.single_seq      = single_seq
        self.use_delta       = use_delta and not single_seq

        if use_cnn:
            self.ref_cnn = MultiKernelCNN(in_ch, cnn_branch_ch, kernels)
            cnn_out      = self.ref_cnn.out_ch
        else:
            self.ref_cnn = nn.Identity()
            cnn_out      = in_ch
        self.ref_proj = nn.Conv1d(cnn_out, transformer_dim, kernel_size=1)

        if tie_branches:
            # Same module object -> same weights. nn.Module de-duplicates
            # shared parameters, so the optimiser still sees them once.
            self.alt_cnn, self.alt_proj = self.ref_cnn, self.ref_proj
        else:
            self.alt_cnn  = (MultiKernelCNN(in_ch, cnn_branch_ch, kernels)
                             if use_cnn else nn.Identity())
            self.alt_proj = nn.Conv1d(cnn_out, transformer_dim, kernel_size=1)

        self.pos_enc = PositionalEncoding(transformer_dim)

        if use_transformer:
            enc_layer = nn.TransformerEncoderLayer(
                d_model=transformer_dim, nhead=nhead,
                dim_feedforward=ff_dim, dropout=dropout,
                activation="gelu", batch_first=True, norm_first=True,
            )
            self.transformer = nn.TransformerEncoder(enc_layer, num_layers=num_layers)
        else:
            self.transformer = None

        self.pooler = MutationAwarePooling(transformer_dim, use_delta=self.use_delta)

        n_streams = 1 if single_seq else (3 if self.use_delta else 2)
        self.classifier = nn.Sequential(
            nn.Linear(transformer_dim * n_streams, 256), nn.GELU(), nn.Dropout(dropout),
            nn.Linear(256, 64),                          nn.GELU(), nn.Dropout(dropout),
            nn.Linear(64, 1),
        )

    def encode_branch(self, x, cnn, proj):
        x = x.transpose(1, 2)               # [B, 5, L]
        x = proj(cnn(x)).transpose(1, 2)    # [B, L, D]
        x = self.pos_enc(x)
        return self.transformer(x) if self.transformer is not None else x

    def forward(self, ref_x, alt_x, return_aux=False):
        alt_h = self.encode_branch(alt_x, self.alt_cnn, self.alt_proj)

        if self.single_seq:                 # Baseline D: ALT only, no comparison
            _, alt_g, _, _, alt_attn, _ = self.pooler(alt_h, alt_h, None)
            logits = self.classifier(alt_g).squeeze(-1)
            if return_aux:
                return logits, {"alt_h": alt_h, "alt_attn": alt_attn, "alt_g": alt_g}
            return logits

        ref_h   = self.encode_branch(ref_x, self.ref_cnn, self.ref_proj)
        delta_h = (alt_h - ref_h) if self.use_delta else None   # explicit Δ-learning

        ref_g, alt_g, delta_g, ref_attn, alt_attn, delta_attn = \
            self.pooler(ref_h, alt_h, delta_h)

        streams = [ref_g, alt_g] + ([delta_g] if self.use_delta else [])
        logits  = self.classifier(torch.cat(streams, dim=-1)).squeeze(-1)

        if return_aux:
            return logits, {
                "ref_h": ref_h, "alt_h": alt_h, "delta_h": delta_h,
                "ref_attn": ref_attn, "alt_attn": alt_attn, "delta_attn": delta_attn,
                "ref_g": ref_g, "alt_g": alt_g, "delta_g": delta_g,
            }
        return logits

Model architecture defined.

PositionalEncoding


Task: Inject positional information into the sequence, since Transformers have no inherent sense of sequence order.


This module precomputes a fixed sinusoidal positional encoding matrix (pe) of shape [max_len, d_model] following the standard *Attention Is All You Need* formulation, where sine functions are applied to even dimensions and cosine functions to odd dimensions. During the forward pass, the positional encoding corresponding to the input sequence length is added directly to the input tensor x. This provides every position within the 1024 bp sequence with a unique positional representation while preserving the learned feature embeddings.


---


MultiKernelCNN


Task: Extract local sequence motifs at multiple receptive field sizes.


The module consists of three parallel Conv1D branches with kernel sizes of 3, 7, and 15, each followed by Batch Normalization and a GELU activation function. Smaller kernels capture fine-grained sequence motifs, whereas larger kernels learn broader contextual patterns. During the forward pass, the outputs from all three convolutional branches are concatenated along the channel dimension, producing a richer multi-scale representation than could be achieved with a single kernel size.


---


MutationAwarePooling


Task: Aggregate sequence-level representations while emphasizing the mutation site.


This attention-based pooling module converts sequence representations of shape [B, L, D] into fixed-length vectors. It learns three independent attention gates corresponding to the REF, ALT, and Δ streams. The module computes the average absolute magnitude of the difference representation (delta_mag) at each sequence position and uses this value to enhance the attention logits. Consequently, positions where the REF and ALT sequences differ most receive higher attention weights across all streams.


During the forward pass, the attention scores are normalized using a softmax function and used to compute weighted sums over the sequence length, producing three pooled feature vectors: ref_g, alt_g, and delta_g.


For ablation experiments, the module supports use_delta=False, which disables Δ-based attention enhancement and removes the delta stream, resulting in conventional attention pooling.


---


MutationAwareBRCAClassifierV2


Task: Perform end-to-end pathogenicity prediction while integrating explicit mutation-difference learning and supporting systematic ablation studies.


This class serves as the complete model architecture and orchestrates all feature extraction, representation learning, pooling, and classification stages.


Model Initialization


The constructor builds the REF and ALT encoding branches. When tie_branches=True, both branches share the same CNN and projection weights, forming a Siamese architecture. Weight sharing guarantees that identical REF and ALT sequences produce identical latent representations, ensuring that


\[

\Delta_h = 0

\]


for identical inputs. This property makes the learned Δ representation meaningful rather than introducing unnecessary noise.


The constructor also configures the ablation switches (use_cnn, use_transformer, use_delta, and single_seq), enabling individual components to be disabled when constructing the baseline architectures presented in the thesis.


Branch Encoding


The encode_branch() function defines the shared processing pipeline for both REF and ALT sequences. Each branch performs the following operations:


  1. Input reshaping.
  2. Multi-scale feature extraction using MultiKernelCNN.
  3. Channel projection to the Transformer embedding dimension using a 1×1 convolution.
  4. Addition of sinusoidal positional encodings.
  5. Contextual representation learning through the Transformer encoder (or bypassed when use_transformer=False).

Because both REF and ALT use the same encoding pipeline, the extracted representations remain directly comparable.


Forward Pass


During inference, the model first encodes the ALT sequence.


If single_seq=True (Baseline D), only the ALT representation is pooled and classified, providing the standard single-sequence baseline without any sequence comparison.


Otherwise, the REF sequence is also encoded, after which the explicit mutation-difference representation is computed as


\[

\Delta_h = ALT_h - REF_h

\]


This explicit Δ-learning mechanism represents the primary methodological contribution of the proposed architecture.


The REF, ALT, and Δ representations are then processed by MutationAwarePooling, producing three fixed-length vectors (ref_g, alt_g, and delta_g). These vectors are concatenated and passed to the classifier for final prediction.


When return_aux=True, the model additionally returns intermediate hidden representations and attention weights for downstream explainability analyses, including Integrated Gradients, Absolute Gradient, and In Silico Mutagenesis (ISM).

            logits = model(ref_x, alt_x)
            loss   = criterion(logits, y)

        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()

        total_loss += loss.item() * y.size(0)
        preds_all.extend(torch.sigmoid(logits).detach().cpu().numpy().tolist())
        labels_all.extend(y.detach().cpu().numpy().tolist())

    return total_loss / len(loader.dataset), np.array(preds_all), np.array(labels_all)


@torch.no_grad()
def evaluate(model, loader, criterion, device):
    model.eval()
    total_loss, preds_all, labels_all = 0.0, [], []

    for batch in loader:
        ref_x = batch["ref"].to(device, non_blocking=True)
        alt_x = batch["alt"].to(device, non_blocking=True)
        y     = batch["label"].to(device, non_blocking=True)

        logits = model(ref_x, alt_x)
        loss   = criterion(logits, y)

        total_loss += loss.item() * y.size(0)
        preds_all.extend(torch.sigmoid(logits).cpu().numpy().tolist())
        labels_all.extend(y.cpu().numpy().tolist())

    return total_loss / len(loader.dataset), np.array(preds_all), np.array(labels_all)

Note — How Cell 11's training loop connects to the model classes in Cell 9


train_one_epoch and evaluate never mention MultiKernelCNN, MutationAwarePooling,

or MutationAwareBRCAClassifierV2 by name. They don't need to — the connection happens

through Python's object-calling convention, not through direct references.


1. Calling an object with () triggers __call__


When a class defines __call__, writing obj(x, y) is automatically translated by

Python into obj.__call__(x, y).


<pre class="nb-md-codeblock"><code>class Doubler:

def __call__(self, x):

return x * 2


d = Doubler()

d(5) # same as d.__call__(5) -&gt; 10</code></pre>


2. nn.Module (PyTorch's base class) defines __call__ to run forward()


Every model class here (MutationAwareBRCAClassifierV2, MultiKernelCNN,

MutationAwarePooling) subclasses nn.Module. PyTorch's nn.Module.__call__

(written inside PyTorch itself — never shown in this notebook) does some

bookkeeping and then calls your forward() method.


So in Cell 11:


<pre class="nb-md-codeblock"><code>logits = model(ref_x, alt_x)</code></pre>


really means:


<pre class="nb-md-codeblock"><code>model.__call__(ref_x, alt_x) # PyTorch&#x27;s built-in dispatch

-&gt; model.forward(ref_x, alt_x) # the forward() you wrote in Cell 9</code></pre>

# Shared utilities

def summarize_attr(attr_tensor) -> np.ndarray:
    """
    Sum absolute attributions across base channels → [L] importance scores.
    """
    return np.abs(attr_tensor.detach().cpu().numpy()[0]).sum(axis=-1)


def absolute_grad_per_position(grad_tensor) -> np.ndarray:
    """
    Sum absolute gradients across channels → [L] importance scores.
    """
    return np.abs(grad_tensor.detach().cpu().numpy()[0]).sum(axis=-1)


def get_mut_region_from_sample(sample, flank=60):
    """
    Return (left, right, var_start, var_end) plot window.
    """
    var_start = sample["var_start"]
    var_end = sample["var_end"]
    center = (var_start + var_end) // 2
    L = sample["ref"].shape[0]

    left = max(0, center - flank)
    right = min(L, center + flank)

    return left, right, var_start, var_end


def find_diff_region(ref_seq, alt_seq):
    """
    Return first and last differing positions between REF and ALT sequences.
    """
    diffs = [i for i, (r, a) in enumerate(zip(ref_seq, alt_seq)) if r != a]

    if len(diffs) == 0:
        return None

    return min(diffs), max(diffs)


@torch.no_grad()
def predict_prob(model, ref_x, alt_x, device) -> float:
    """
    Predict probability for a REF/ALT sequence pair.
    """
    model.eval()

    logit = model(
        ref_x.unsqueeze(0).to(device),
        alt_x.unsqueeze(0).to(device),
    )

    return float(torch.sigmoid(logit).item())


# ────────────────────────────────────────────────────────────
# Integrated Gradients
# ────────────────────────────────────────────────────────────

class _IGWrapper(nn.Module):
    def __init__(self, model):
        super().__init__()
        self.model = model

    def forward(self, ref_x, alt_x):
        return self.model(ref_x, alt_x)


def run_integrated_gradients(model, sample, device):
    """
    Compute Integrated Gradients for REF and ALT inputs.
    """
    model.eval()

    ig = IntegratedGradients(_IGWrapper(model).to(device))

    ref_x = sample["ref"].unsqueeze(0).to(device)
    alt_x = sample["alt"].unsqueeze(0).to(device)

    attr, delta = ig.attribute(
        inputs=(ref_x, alt_x),
        baselines=(
            torch.zeros_like(ref_x),
            torch.zeros_like(alt_x),
        ),
        return_convergence_delta=True,
    )

    return ref_x, alt_x, attr[0], attr[1], delta


# ────────────────────────────────────────────────────────────
# Guided Absolute Gradient
# ────────────────────────────────────────────────────────────

def run_guided_absolute_grad(model, sample, device):
    """
    Compute Guided Absolute Gradient importance scores.
    """
    model.eval()

    ref_x = (
        sample["ref"]
        .unsqueeze(0)
        .to(device)
        .clone()
        .detach()
        .requires_grad_(True)
    )

    alt_x = (
        sample["alt"]
        .unsqueeze(0)
        .to(device)
        .clone()
        .detach()
        .requires_grad_(True)
    )

    model.zero_grad()

    logits = model(ref_x, alt_x)
    pred_prob = torch.sigmoid(logits).item()

    logits.sum().backward()

    ref_scores = absolute_grad_per_position(ref_x.grad)
    alt_scores = absolute_grad_per_position(alt_x.grad)

    return (
        ref_x,
        alt_x,
        ref_x.grad,
        alt_x.grad,
        ref_scores,
        alt_scores,
        pred_prob,
    )


# ────────────────────────────────────────────────────────────
# In-Silico Mutagenesis
# ────────────────────────────────────────────────────────────

def in_silico_mutagenesis_alt(model, sample, start, end, device):
    """
    Systematically mutate each ALT nucleotide.

    Returns:
        scores : ndarray of shape [window_length, 5]
        base_prob : original prediction probability
    """
    ref_x = sample["ref"]
    alt_x = sample["alt"]

    base_prob = predict_prob(model, ref_x, alt_x, device)

    scores = np.zeros((end - start, 5), dtype=np.float32)

    for i, pos in enumerate(range(start, end)):
        orig = int(alt_x[pos].argmax().item())

        for b in range(5):
            if b == orig:
                continue

            mut = alt_x.clone()
            mut[pos, :] = 0.0
            mut[pos, b] = 1.0

            scores[i, b] = (
                predict_prob(model, ref_x, mut, device)
                - base_prob
            )

    return scores, base_prob


# ────────────────────────────────────────────────────────────
# Mutation Site Ranking
# ────────────────────────────────────────────────────────────

def mutation_site_rank(scores, var_start, var_end) -> float:
    """
    Fraction of positions with lower attribution than the mutation site.

    Returns:
        1.0 -> mutation is the highest-ranked position.
    """
    mut_score = scores[var_start:var_end].max()

Note — Integrated Gradients: Inputs, Outputs, and the Mechanism Between Them


Conceptually, IG needs:

  1. A differentiable model/function that takes some input and returns a scalar output.
  2. The real input to be explained.
  3. A baseline input — the "zero information" reference point, same shape as the real input.
  4. (Internally) a number of interpolation steps along the path from baseline → input.

Conceptually, IG returns:

  • One attribution score per input feature, same shape as the input — how much each individual value contributed to the output.
  • A convergence delta — a scalar measuring how closely the numerical approximation matches the theoretical completeness guarantee.

Important — the model's output is not a bystander. The inputs above are just raw material; they don't carry any notion of "importance" by themselves. Importance only exists because IG *runs the model repeatedly and watches how its output responds*. Concretely, between "inputs in" and "attributions out," IG does:


  1. Builds a series of in-between sequences walking from the baseline to the real input (baseline → 25% real → 50% real → ... → 100% real).
  2. At every step, runs the model forward and reads off its output (the pathogenicity logit).
  3. Computes the gradient of that output with respect to every input feature, at every step — i.e. "if I nudge this feature right now, how much does the output move?"
  4. Averages those output-sensitivities across the whole walk, then multiplies by (real_value - baseline_value).

So "how much did position 512 matter" really means "how much did the model's output change as position 512 went from 'nothing' to its real value, averaged across the whole interpolation path." The attribution score is extracted from tracking the output, not read off the inputs alone — the model's output is central to the computation at every single step, not just the final answer.

Note — Integrated Gradients (IG) vs. Guided AbsoluteGrad (AG)


Both methods answer the same question — "how important is each position to the model's decision?" — and both produce the same *kind* of output (a bar chart, one bar per position). The difference is entirely in how each bar's height is calculated.


AbsoluteGrad (AG) — one snapshot

Stand at the real sequence and take exactly one gradient reading: "if I nudge this position slightly *right now*, how much does the output move?" That single number becomes the bar height. One forward pass, one backward pass — done.


Integrated Gradients (IG) — a whole journey, averaged

Start from an "empty" sequence (all-zeros baseline — no information) and walk in small steps toward the real sequence. At every step along that walk, take a gradient reading, then average all of those readings together. That average becomes the bar height.


Why IG does the extra work: a single gradient reading (AG) can be misleading. If the model is already very confident about a position, nudging it slightly barely changes the output anymore — even if that position is genuinely the most important one in the sequence. AG would report a small bar there, wrongly implying "not important," purely because the model has saturated. IG avoids this by also checking earlier points in the walk, when the model was less confident and more sensitive — averaging over the whole path recovers signal a single snapshot can miss.


| | Integrated Gradients (IG) | AbsoluteGrad (AG) |

|---|---|---|

| Core question | "How much did this position contribute, vs. a baseline of 'nothing'?" | "How sensitive is the output to this position, right now?" |

| How it's measured | Many gradient readings, averaged along a path from baseline → real input | One single gradient reading, at the real input |

| Needs a baseline? | Yes — all-zero tensor | No |

| Speed / cost | Slower, more compute | Fast, cheap |

| Saturation problem | Avoided — averaging over the path recovers signal even where the final gradient is flat | Can be misled — near-zero gradient at an already-confident (but truly important) position |

| Mathematical guarantee | Yes — attributions ≈ sum to the real output change (checked via delta) | None |

| Direction of effect | Signed (positive → pathogenic, negative → benign); collapsed to absolute value only when plotted | Direction lost immediately — always absolute value |

| Used for REF vs ALT comparison (Delta chart)? | No | Yes — cheap enough to compute twice and subtract (Figure F.8: ALT − REF) |

| In this notebook | Figures F.4 & F.5 | Figures F.6, F.7 & F.8 |

| Role in the analysis | The rigorous, "gold standard" check | A cheaper, quick cross-check confirming IG's result isn't a fluke |


Why the notebook uses both: not redundancy — it's a cross-check. If the cheap, rough method (AG) and the slow, rigorous method (IG) agree — both spike at the mutation site — that's stronger evidence than either alone, since it means the result isn't just an artifact of one technique's particular quirks.

Note — Figure F.9: In-silico Mutagenesis (ISM) Heatmap


What ISM does, in simple words: IG and AbsoluteGrad both rely on the model's *gradient* — a fast mathematical shortcut for sensitivity. ISM is different — it's brute-force and literal: for every position in the window, actually substitute in every other possible base, re-run the model for real, and record how much the prediction changes. No math shortcuts, just "swap the letter, re-run the model, see what happens," repeated many times.


Why this matters: it's the most direct, assumption-free check possible. If ISM's result agrees with IG and AG (which rely on gradients), that's a third, independent confirmation that the model is truly reacting to the right positions — not an artifact of how gradients happen to behave.

def fetch_clinvar_by_variation_id(variation_id: str, retries: int = 3) -> dict:
    """
    Fetch live ClinVar record via NCBI Entrez E-utilities.
    Handles both 'clinical_significance' and
    'germline_classification' fields,
    with exponential back-off on failure.
    """

    url = (
        "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi"
        f"?db=clinvar&id={variation_id}&retmode=json"
        f"&tool={Entrez.tool}&email={Entrez.email}"
    )

    for attempt in range(retries):
        try:
            resp = requests.get(url, timeout=30)
            resp.raise_for_status()

            data = resp.json()
            doc = data.get("result", {}).get(str(variation_id), {})

            # Try clinical_significance
            sig_raw = doc.get("clinical_significance", {})

            if isinstance(sig_raw, str):
                description = sig_raw
                review_status = doc.get("review_status", "unknown")
            elif isinstance(sig_raw, dict):
                description = sig_raw.get("description", "unknown")
                review_status = sig_raw.get("review_status", "unknown")
            else:
                description = "unknown"
                review_status = "unknown"

            # Fallback to germline_classification
            if description == "unknown":
                gc = doc.get("germline_classification", {})
                if isinstance(gc, dict):
                    description = gc.get("description", "unknown")
                    review_status = gc.get("review_status", review_status)
                elif isinstance(gc, str):
                    description = gc

            genes = doc.get("genes", [])
            gene_symbol = genes[0].get("symbol", "") if genes else ""

            return {
                "variation_id": variation_id,
                "ncbi_significance": description,
                "ncbi_review_status": review_status,
                "gene_symbol": gene_symbol,
                "variant_type": doc.get("obj_type", "unknown"),
            }

        except Exception as e:
            print(f"Attempt {attempt + 1} failed: {e}")
            time.sleep(2 ** attempt)

    return {
        "variation_id": variation_id,
        "ncbi_significance": "error",
        "ncbi_review_status": "error",
    }

# Shared label normalisation (mirrors the Cell 3 rule)

def normalise_significance(sig: str) -> int:
    """ClinVar significance string -> 1 pathogenic / 0 benign / -1 unusable."""
    s = str(sig).strip().lower()
    if not s or s in ("unknown", "error", "no_id"):
        return -1
    if "conflicting" in s:
        return -1
    if "uncertain" in s or "vus" in s:
        return -1
    if "benign" in s:      # checked first: "Benign/Likely benign" wins over substrings
        return 0
    if "pathogenic" in s:
        return 1
    return -1

# ============================================================
# SPDI -> VCF-style coordinates
#   SPDI:  NC_000017.11:43124026:G:A   (position is 0-based)
#   Yields the SAME convention as ReferenceAlleleVCF/AlternateAlleleVCF,
#   so windows built here are encoded exactly like the training data.
#   Verified against build_ref_alt_window for SNV/insertion/deletion/delins.
# ============================================================
SPDI_CHR = {f"NC_{i:06d}": str(i) for i in range(1, 23)}
SPDI_CHR["NC_000023"] = "X"
SPDI_CHR["NC_000024"] = "Y"

def spdi_to_vcf(spdi: str, genome):
    """Return (chrom, pos_1based, ref_allele, alt_allele) or None if unusable."""
    if not spdi or str(spdi).count(":") != 3:
        return None
    acc, pos0, deleted, inserted = str(spdi).split(":")
    chrom = SPDI_CHR.get(acc.split(".")[0])
    if chrom is None:
        return None                       # unplaced / MT / patch scaffold
    try:
        pos0 = int(pos0)
    except ValueError:
        return None
    deleted, inserted = deleted.strip().upper(), inserted.strip().upper()

    if deleted and inserted:
        # SNV / MNV / delins — both sides non-empty, no VCF anchor base needed
        return chrom, pos0 + 1, deleted, inserted

    # pure insertion or pure deletion — VCF requires the preceding anchor base
    if pos0 == 0:
        return None
    anchor = str(genome[get_chr_name(chrom)][pos0 - 1:pos0]).upper()
    if len(anchor) != 1 or anchor not in "ACGT":
        return None
    return chrom, pos0, anchor + deleted, anchor + inserted

def parse_clinvar_docsum(doc: dict) -> dict:
    """Extract classification, review status, gene and GRCh38 SPDI from one docsum."""
    gc = doc.get("germline_classification", {})
    if isinstance(gc, dict):
        desc      = gc.get("description", "unknown")
        review    = gc.get("review_status", "unknown")
        last_eval = gc.get("last_evaluated", "")
    else:
        desc, review, last_eval = str(gc), "unknown", ""

    if str(desc).lower() in ("", "unknown"):          # older field name fallback
        cs = doc.get("clinical_significance", {})
        if isinstance(cs, dict):
            desc   = cs.get("description", desc)
            review = cs.get("review_status", review)
        elif isinstance(cs, str):
            desc = cs

    genes = doc.get("genes", [])
    vset  = doc.get("variation_set", [])
    return {
        "variation_id":        str(doc.get("uid", "")),
        "ncbi_significance":   desc,
        "ncbi_review_status":  review,
        "ncbi_last_evaluated": last_eval,
        "gene_symbol":         genes[0].get("symbol", "") if genes else "",
        "variant_type":        doc.get("obj_type", "unknown"),
        "canonical_spdi":      vset[0].get("canonical_spdi", "") if vset else "",
    }

def fetch_clinvar_summaries(id_list, batch_size: int = 100, retries: int = 3):
    """Batched esummary — ~100 IDs per request instead of one request per variant."""
    out = []
    n_batches = (len(id_list) + batch_size - 1) // batch_size
    for bi in range(n_batches):
        batch  = id_list[bi * batch_size:(bi + 1) * batch_size]
        params = _ncbi_params({"db": "clinvar", "id": ",".join(batch),
                               "retmode": "json"})
        for attempt in range(retries):
            try:
                r = requests.get(f"{EUTILS}/esummary.fcgi", params=params, timeout=60)
                r.raise_for_status()
                result = r.json().get("result", {})
                for uid in result.get("uids", []):
                    out.append(parse_clinvar_docsum(result[uid]))
                break
            except Exception as e:
                print(f"  batch {bi+1}/{n_batches} attempt {attempt+1} failed: {e}")
                time.sleep(2 ** attempt)
        time.sleep(NCBI_SLEEP)
    return out

20. Model Evaluation with NCBI ClinVar Lookup (Stratified Sampling)


This section evaluates the trained variant classification model against external clinical annotations retrieved from NCBI ClinVar.


The evaluation process:

  1. Creates a balanced evaluation dataset by sampling variants across:
  • Variant types:
  • Single nucleotide variants (SNVs)
  • Deletions
  • Insertions
  • Indels
  • Clinical labels:
  • 0 → Benign
  • 1 → Pathogenic

  1. Runs model inference on the selected variants to obtain:
  • Predicted pathogenicity probability
  • Binary model prediction

  1. Queries NCBI ClinVar using the VariationID to retrieve:
  • Clinical significance
  • Review status

  1. Converts ClinVar clinical significance into binary labels:
  • Pathogenic → 1
  • Benign → 0
  • Conflicting / Unknown / VUS → ignored (-1)

  1. Saves all evaluation results for further analysis.

Why Stratified Sampling?


The dataset may contain imbalanced distributions of:

  • Variant types
  • Pathogenic vs benign examples

Stratified sampling ensures that the evaluation set contains a representative mixture of different variant categories and labels instead of randomly selecting only dominant classes.


---


Model Prediction and NCBI Validation


For every selected variant:


Model Prediction


The variant reference and alternative allele representations are passed through the trained model.


The model outputs:


$$

P(pathogenic) = \sigma(logit)

$$


where:


  • $\sigma$ is the sigmoid activation function
  • Output probability ranges from 0 to 1

Classification threshold:


$$

Prediction =

\begin{cases}

1 & probability \geq 0.5 \\

0 & probability < 0.5

\end{cases}

$$

Evaluation Metrics


ROC-AUC


Measures how well the model separates pathogenic and benign variants across all probability thresholds.


$$

AUC = P(score_{pathogenic} > score_{benign})

$$


Higher values indicate better discrimination.


---


Area Under Precision-Recall Curve (AUPRC)


Evaluates model performance under class imbalance.


It focuses on:


  • Precision:

$$

Precision=\frac{TP}{TP+FP}

$$


  • Recall:

$$

Recall=\frac{TP}{TP+FN}

$$


A higher AUPRC indicates better identification of pathogenic variants.


---


Matthews Correlation Coefficient (MCC)


A balanced classification metric considering:


  • True positives
  • True negatives
  • False positives
  • False negatives

$$

MCC=

\frac{TP \times TN - FP \times FN}

{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}

$$


Range:


  • +1 → Perfect prediction
  • 0 → Random prediction
  • -1 → Completely incorrect prediction

---


Balanced Accuracy


Useful for imbalanced datasets.


It averages:


  • Sensitivity (Recall of pathogenic variants)
  • Specificity (Recall of benign variants)

$$

Balanced Accuracy =

\frac{Sensitivity + Specificity}{2}

$$

Why This Matters for the Thesis


1. The Generalization Question


A common failure mode in genomic ML papers is that a model looks great in

aggregate but is actually just doing well on a handful of over-represented

genes (e.g., BRCA1, BRCA2, TP53 — genes with thousands of curated ClinVar

entries) while performing poorly everywhere else. If those few genes

dominate the test set, overall AUC/accuracy numbers can look strong even

though the model hasn't learned anything generalizable about sequence-level

pathogenicity — it may have just learned gene-specific shortcuts (e.g.,

"most BRCA1 missense variants in this dataset are pathogenic, so predict

pathogenic whenever the input pattern looks like BRCA1").


The per-gene breakdown is how this is checked. If accuracy and AUC stay

consistently high across a wide range of genes with reasonable N, that's

evidence the model is learning something about variant pathogenicity

itself, not memorizing gene-specific label frequencies.


2. Why AUC Near 0.5 With "Decent" Accuracy Is a Red Flag


Accuracy and AUC measure different things:


  • Accuracy checks whether the final thresholded prediction

(model_pred, using the 0.5 cutoff) matches the true label.

  • AUC checks whether the model's raw probability scores rank pathogenic

variants above benign ones, across all thresholds.


Example: a gene where 18 of 20 variants are pathogenic and 2 are

benign. A model that outputs a probability around 0.6 for *every* variant

in that gene — regardless of the actual sequence — would get 90% accuracy

(it predicts "pathogenic" every time, and 90% of the true labels are

pathogenic), but its AUC would sit right around 0.5, because the

probabilities don't actually discriminate between the two classes — they're

just uniformly biased toward the majority label. High accuracy here is an

artifact of class imbalance within that gene's subgroup, not evidence the

model is examining the sequence and making a real judgment call.


Takeaway: when accuracy is noticeably higher than AUC for a given gene,

flag it explicitly as a limitation. It tells a careful reader that for that

gene, the model's confidence scores aren't reliably informative, even

though the final classification looks fine on the surface.


3. Representativeness View vs. Worst-Case View


gene_df is sorted by N (variant count) and truncated to the top 20, so

the current figure only shows how the model does on the genes with the

*most* data. It doesn't show where the model does *worst*. A gene with

only 5 variants and an AUC of 0.3 wouldn't appear at all if it's not in the

top 20 by count — but that's exactly the kind of result a supervisor might

probe during a viva ("show me where it fails").


Suggested companion figure: same code structure, but sort by AUC

ascending instead of N descending, with a minimum N threshold (e.g.,

N >= 5) to avoid noisy single-digit samples dominating the "worst" list.

This directly answers the failure-mode question and shows the limitation

was found proactively rather than only presenting favorable results —

generally a stronger position to defend.

NCBI ClinVar Review Status Categories


ClinVar review status indicates the level of evidence and confidence supporting a variant's clinical significance classification. It reflects how the classification was determined, not whether the variant is benign or pathogenic.


| Review Status | Stars | Definition |

|---------------|:-----:|------------|

| Reviewed by expert panel | ★★★ | The variant classification has been reviewed and agreed upon by a recognized expert panel (e.g., ClinGen Variant Curation Expert Panel). This represents one of the highest confidence levels in ClinVar, as experts systematically evaluate all available evidence before reaching a consensus. |

| Criteria provided, multiple submitters, no conflicts | ★★ | Two or more independent laboratories submitted classifications using documented evaluation criteria (typically ACMG/AMP guidelines), and all agreed on the clinical significance. Independent agreement increases confidence in the classification. |

| Criteria provided, single submitter | ★ | A single laboratory or organization classified the variant and documented the criteria or evidence used to support its interpretation. Although the methodology is transparent, the classification has not been independently confirmed by other submitters. |

| No assertion criteria provided | 0 | A clinical significance classification was submitted, but the submitter did not provide the criteria, evidence, or methodology used to reach that conclusion. The classification is available, but its supporting rationale cannot be independently assessed, making it the lowest confidence review category among definitive ClinVar labels. |

27. Architectural Ablation Study


This experiment evaluates the contribution of each major component of the proposed architecture by systematically removing or modifying one component at a time while keeping all other experimental conditions identical.


Unlike the final model evaluation, all architectures are trained on the same subset of the training data, using the same validation set, same optimizer, same random seed, same number of epochs, and same hyperparameters. This ensures that any performance differences are attributable solely to the architectural changes rather than differences in training conditions.


---


Experimental Procedure


The ablation study follows the workflow below:


<pre class="nb-md-codeblock"><code>Training Subset (120,000 samples)

│

├────────► Proposed Framework

├────────► Baseline A

├────────► Baseline B

├────────► Baseline C

└────────► Baseline D

│

▼

Train for 6 Epochs

│

▼

Validation Subset (30,000 samples)

│

▼

Performance Evaluation</code></pre>


Each architecture is trained independently before being evaluated on the identical validation dataset.


---


Ablation Configurations


Five model configurations are evaluated:


| Configuration | Description |

|---------------|-------------|

| Proposed Framework (Full) | Complete architecture with all proposed components enabled. |

| Baseline A: Without Delta Learning | Removes the delta-learning mechanism while retaining the remaining architecture. |

| Baseline B: Without Transformer | Removes the Transformer encoder and evaluates the CNN branch alone. |

| Baseline C: Without Multi-Kernel CNN | Removes the multi-kernel convolutional feature extractor while retaining the Transformer branch. |

| Baseline D: Single Sequence | Uses only a single DNA sequence instead of jointly processing the reference and alternative sequences. |


---


Model Evaluation


After training each architecture, predictions are generated for every sample in the validation set.


The evaluation function returns:


<pre class="nb-md-codeblock"><code>ys</code></pre>


Ground-truth labels:


<pre class="nb-md-codeblock"><code>0 = Benign

1 = Pathogenic</code></pre>


and


<pre class="nb-md-codeblock"><code>probs</code></pre>


Predicted pathogenicity probabilities:


<pre class="nb-md-codeblock"><code>0.03

0.92

0.76

0.11

...</code></pre>


Binary predictions are then obtained using a threshold of 0.5:


<pre class="nb-md-codeblock"><code>preds = (probs &gt;= 0.5).astype(int)</code></pre>


---


Performance Metrics


Each architecture is evaluated using the following metrics.


ROC-AUC


Measures the model's ability to distinguish between benign and pathogenic variants across all classification thresholds.


Higher values indicate better discrimination.


---


Area Under the Precision-Recall Curve (AUPRC)


Evaluates the trade-off between precision and recall, particularly useful for imbalanced datasets.


---


Matthews Correlation Coefficient (MCC)


Measures the overall quality of binary classification by considering all elements of the confusion matrix.


\[

MCC=

\frac{TP\times TN-FP\times FN}

{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}

\]


Values range from:


  • +1 : Perfect prediction
  • 0 : Random prediction
  • −1 : Complete disagreement

---


Balanced Accuracy


Instead of conventional accuracy, this study reports Balanced Accuracy, which compensates for class imbalance.


\[

Balanced\ Accuracy

=

\frac{Sensitivity+Specificity}{2}

\]


where


\[

Sensitivity=\frac{TP}{TP+FN}

\]


and


\[

Specificity=\frac{TN}{TN+FP}

\]


Balanced Accuracy provides a more reliable estimate of classification performance when the dataset contains unequal numbers of benign and pathogenic variants.


---


Fair Comparison


All architectures are evaluated under identical experimental settings:


  • Same training subset (120,000 variants)
  • Same validation subset (30,000 variants)
  • Same random seed
  • Same optimizer (AdamW)
  • Same learning rate
  • Same batch size
  • Same number of training epochs (6)

Consequently, differences in ROC-AUC, AUPRC, MCC, and Balanced Accuracy directly reflect the contribution of the architectural component that was removed or modified, providing a fair assessment of the effectiveness of each component within the proposed framework.
